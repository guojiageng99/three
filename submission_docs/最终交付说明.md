# 最终交付说明

本目录用于放置课程作业最终提交材料。

## 必交材料

- `题目需求理解与分析报告_终稿.docx`
- `解题技术思路和最优方案报告_终稿.docx`
- `generative agents_最终版.pptx`

## 源文件与生成方式

- Word 报告源文件：
  - `题目需求理解与分析报告_终稿.md`
  - `解题技术思路和最优方案报告_终稿.md`
- PPT 基准文件：
  - `generative agents.pptx`

生成命令：

```bat
scripts\build_final_submission_docs.bat
```

或分别运行：

```bat
python scripts\build_submission_docx.py
python scripts\extend_group_ppt.py
```

## 注意事项

- `build_submission_docx.py` 会优先查找项目中的 `00作业模板.docx` 或文件名包含 `00`、`作业`、`模板` 的 Word 模板。
- 如果没有找到 `00作业模板`，脚本会直接报错，避免生成不符合课程模板的 Word 文件。
- `extend_group_ppt.py` 不覆盖组长原始 PPT，而是从 `generative agents.pptx` 生成 `generative agents_最终版.pptx`。
- 新增 PPT 页面会从组长 PPT 的最后一页继续追加，尽量沿用原版式和风格。

## LLM 模式录屏（可选）

答辩或录视频时如需展示 DeepSeek 生成效果：

1. 在 `backend/.env` 中配置（该文件不提交，参考 `backend/.env.example`）：
   - `SIMULATION_MODE=llm`
   - `LLM_BASE_URL=https://api.deepseek.com`
   - `LLM_MODEL=deepseek-v4-pro`
2. 启动后端后，侧栏 `last_llm_call_status` 显示 `ok` 表示 LLM 调用成功。
3. 若网络不稳定或 API 失败，系统自动回退规则模式，不影响演示继续。

详细步骤见仓库根目录 [README.md](../README.md) 的「LLM 模式配置方式」一节。
